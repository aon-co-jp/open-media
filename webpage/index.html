open-media

概要 / Overview

CD・DVD・Blu-rayの書き込みと音声・動画の変換(make-disk)と、高音質プレーヤー(open-bar)を1つにしたアプリです。Windows / macOS / Linux / Android(スマホ・タブレット)に対応します。

One app that combines disc burning and audio/video conversion (make-disk) with a hi-fi player (open-bar), for Windows, macOS, Linux and Android (phones and tablets).

  • 音楽CDを、排他モード+高品質アップサンプル(例: 44.1 kHz → 352.8 kHz、32bit)で再生 / Plays audio CDs in exclusive mode with high-quality upsampling (e.g. 44.1 → 352.8 kHz, 32-bit)
  • DVD・MP4・MKVをFull HD / 4Kへ引き上げながら再生 / Upconverts DVD / MP4 / MKV to Full HD / 4K while playing
  • YouTubeなどの音を、別のDACへ高音質に出し直す(Windows、音楽向け。DRM音声は対象外) / Re-renders system audio (YouTube etc.) to another DAC at higher quality (Windows, for music; DRM audio is out of scope)
  • CD・DVDを入れたら自動で開く設定、拡張子ごとの関連付け、自動更新 / AutoPlay for CDs and DVDs, per-extension file associations, auto-update
