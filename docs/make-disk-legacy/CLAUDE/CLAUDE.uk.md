## Призначення репозиторію

GUI-застосунок (Rust + Tauri) для запису CD/DVD/Blu-ray, конвертації аудіо/відео та створення ISO-образів з єдиною кодовою базою для Windows/macOS/Linux (і Android).
Відмінності платформ обмежено інсталяторами; сам застосунок (`src-tauri/src`, `src`) — єдина кодова база.

## Архітектура

- Фронтенд: `src/` (чистий JS; викликає команди Rust через Tauri IPC за допомогою `window.__TAURI__`, бо «голі» імпорти без збирача не працюють).
- Бекенд: `src-tauri/src/engine/`
  - `probe.rs` — тривалість, кодеки, частота дискретизації, ознаки Dolby через ffprobe (запасний варіант rs-ffmpeg)
  - `convert.rs` — конвертація ffmpeg, керування бітрейтом, обрізання, вирізання кількох ділянок (типово копіювання потоку, для покадрової точності — GPU-кодувальник)
  - `capacity.rs` — максимальний бітрейт за ємністю диска та 4-рівневе попередження про якість
  - `dsd.rs` — власний дельта-сигма-модулятор PCM→1 біт і запис DSF, DoP WAV
  - `cdda.rs` — видобування аудіо-CD (Windows, просте безпечне читання)
  - `iso.rs` / `burn.rs` / `windows_imapi.rs` — створення ISO та запис (IMAPI2 у Windows, xorriso в інших)
  - `ai_upscale.rs` / `cpu_sr.rs` / `audio_sr.rs` — Real-ESRGAN (GPU/CPU), розширення смуги аудіо
  - `mkv_tracks.rs` — збереження/додавання кількох аудіодоріжок і субтитрів у MKV
  - `plugins.rs` / `sidecar.rs` — вбудовані/завантажувані інструменти з керуванням версіями
  - `cpu.rs` — визначення наборів інструкцій CPU через `open-cpu` (підказки швидкості та вибір `-preset` x264)

## Встановлені правила

- **Жодного обходу захисту від копіювання** (CSS/AACS тощо). Лише незахищені диски.
- **Жодного створення Dolby Vision / Atmos / IMAX / 4DX** (ліцензовані); лише збереження копіюванням потоку та сумісні молодші формати.
- **Без MQA** (патенти/комерційна таємниця). Hi-Res дотримується відкритих форматів у дусі `aon-co-jp/open-mqa`.
- **Під час створення DSD PCM одночасно не створюється** (на обладнанні без DSD програвач сам перетворює на PCM). DoP WAV — це дані DSD, тому допустимий.
- Модуляція DSD лишається **послідовною за каналами (побітово ідентичною)**; сегментно-паралельна модуляція за вимірюваннями руйнувала SNR і відхилена.
- «ШІ»-функції описуються чесно: автообрізання за тишею та «ШІ-оптимізація» роздільності/FPS — евристики; розширення смуги аудіо — синтез.
- Full HD на DVD поза стандартом DVD-Video; побутові програвачі не знижують роздільність автоматично. Інтерфейс зберігає це попередження (користувач відмовився від поєднання DVD-Video + файлу Full HD).
- Мови документації: японська — основна; `README/`, `CLAUDE/`, `PORTING/` містять англійську, спрощену китайську, традиційну китайську (Тайвань), корейську, німецьку, французьку, російську, українську, перську (Іран, суфікс файлу `.iran(Perusha)`) та арабську (CLAUDE/PORTING — стисло).

## Правила перевірки

- Успішний CI — не доказ працездатності. Перед звітом про готовність перевіряти по-справжньому: `npm run lint` (eslint `no-undef`), перевірка інтерфейсу в браузері із заглушками Tauri API, тести Rust (`cargo test --lib -- --test-threads=1`) і за можливості E2E на реальних файлах / обладнанні.
- Чесно зазначати, що не перевірено.

Push тегу `v*` запускає `.github/workflows/release.yml`, який збирає інсталятори Windows/macOS/Linux/Android і публікує їх у GitHub Releases.

## Поточний стан (2026-09-23)

Виправлено вирізання ділянок, яке не працювало з розділу 8; під час створення DSD більше не створюється PCM; обрізання перероблено на взаємовиключні ТАК/НІ «за розміром / за часом» (типово розмір) з прапорцями постобробки «заповнити диск» і «ШІ-обрізання тиші»;
додано межі стандартів відтворення (CD / DVD-Video / DVD-Audio / Blu-ray / UHD Blu-ray / лише ПК) за максимальними кГц, розрядністю та бітрейтом. E2E на реальних файлах ще не проводився.
