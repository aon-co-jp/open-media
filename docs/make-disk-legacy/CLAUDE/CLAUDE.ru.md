## Назначение репозитория

GUI-приложение (Rust + Tauri) для записи CD/DVD/Blu-ray, конвертации аудио/видео и создания ISO-образов с единой кодовой базой для Windows/macOS/Linux (и Android).
Различия платформ ограничены установщиками; само приложение (`src-tauri/src`, `src`) — единая кодовая база.

## Архитектура

- Фронтенд: `src/` (чистый JS; вызывает команды Rust через Tauri IPC с помощью `window.__TAURI__`, так как «голые» импорты без сборщика не работают).
- Бэкенд: `src-tauri/src/engine/`
  - `probe.rs` — длительность, кодеки, частота дискретизации, признаки Dolby через ffprobe (запасной вариант rs-ffmpeg)
  - `convert.rs` — конвертация ffmpeg, управление битрейтом, обрезка, вырезание нескольких участков (по умолчанию копирование потока, для покадровой точности — GPU-кодировщик)
  - `capacity.rs` — максимальный битрейт по ёмкости диска и 4-уровневое предупреждение о качестве
  - `dsd.rs` — собственный дельта-сигма-модулятор PCM→1 бит и запись DSF, DoP WAV
  - `cdda.rs` — извлечение аудио-CD (Windows, простое безопасное чтение)
  - `iso.rs` / `burn.rs` / `windows_imapi.rs` — создание ISO и запись (IMAPI2 в Windows, xorriso в остальных)
  - `ai_upscale.rs` / `cpu_sr.rs` / `audio_sr.rs` — Real-ESRGAN (GPU/CPU), расширение полосы аудио
  - `mkv_tracks.rs` — сохранение/добавление нескольких аудиодорожек и субтитров в MKV
  - `plugins.rs` / `sidecar.rs` — встроенные/загружаемые инструменты с управлением версиями
  - `cpu.rs` — определение наборов инструкций CPU через `open-cpu` (подсказки скорости и выбор `-preset` x264)

## Установленные правила

- **Никакого обхода защиты от копирования** (CSS/AACS и т. п.). Только незащищённые диски.
- **Никакого создания Dolby Vision / Atmos / IMAX / 4DX** (лицензируемые); только сохранение копированием потока и совместимые младшие форматы.
- **Без MQA** (патенты/коммерческая тайна). Hi-Res следует открытым форматам в духе `aon-co-jp/open-mqa`.
- **При создании DSD PCM одновременно не создаётся** (на оборудовании без DSD плеер сам преобразует в PCM). DoP WAV — это данные DSD, поэтому допустим.
- Модуляция DSD остаётся **последовательной по каналам (побитово идентичной)**; сегментно-параллельная модуляция по измерениям разрушала SNR и отклонена.
- «ИИ»-функции описываются честно: автообрезка по тишине и «ИИ-оптимизация» разрешения/FPS — эвристики; расширение полосы аудио — синтез.
- Full HD на DVD вне стандарта DVD-Video; бытовые плееры не снижают разрешение автоматически. Интерфейс сохраняет это предупреждение (пользователь отказался от совмещения DVD-Video + файла Full HD).
- Языки документации: японский — основной; `README/`, `CLAUDE/`, `PORTING/` содержат английский, упрощённый китайский, традиционный китайский (Тайвань), корейский, немецкий, французский, русский, украинский, персидский (Иран, суффикс файла `.iran(Perusha)`) и арабский (CLAUDE/PORTING — кратко).

## Правила проверки

- Успешный CI — не доказательство работоспособности. Перед отчётом о готовности проверять по-настоящему: `npm run lint` (eslint `no-undef`), проверка интерфейса в браузере с заглушками Tauri API, тесты Rust (`cargo test --lib -- --test-threads=1`) и по возможности E2E на реальных файлах / оборудовании.
- Честно указывать, что не проверено.

## Выпуски

Push тега `v*` запускает `.github/workflows/release.yml`, который собирает установщики Windows/macOS/Linux/Android и публикует их в GitHub Releases.
