## نقش مخزن

یک برنامهٔ گرافیکی (Rust + Tauri) برای رایت CD/DVD/Blu-ray، تبدیل صوت/ویدئو و ساخت ایمیج ISO، با یک پایگاه کد واحد برای ویندوز/macOS/لینوکس (و اندروید).
تفاوت‌های سکوها فقط به نصب‌کننده‌ها محدود است؛ خود برنامه (`src-tauri/src`، `src`) یک پایگاه کد واحد است.

## معماری

- فرانت‌اند: `src/` (جاوااسکریپت ساده؛ چون importهای بدون مسیر بدون باندلر کار نمی‌کنند، فرمان‌های Rust را از طریق IPC تاوری با `window.__TAURI__` فرا می‌خواند).
- بک‌اند: `src-tauri/src/engine/`
  - `probe.rs` — مدت، کدک‌ها، نرخ نمونه‌برداری و ویژگی‌های Dolby با ffprobe (جایگزین: rs-ffmpeg)
  - `convert.rs` — تبدیل با ffmpeg، کنترل نرخ بیت، برش، برش چند بازه (پیش‌فرض کپی جریان؛ برای برش دقیق در سطح فریم، رمزگذار GPU)
  - `capacity.rs` — بیشینهٔ نرخ بیت بر اساس ظرفیت دیسک و هشدار کیفیت چهارسطحی
  - `dsd.rs` — مدولاتور دلتا-سیگمای اختصاصی PCM→۱ بیتی و نوشتن DSF، WAV از نوع DoP
  - `cdda.rs` — استخراج CD صوتی (ویندوز، خواندن امن ساده)
  - `iso.rs` / `burn.rs` / `windows_imapi.rs` — ساخت ISO و رایت (در ویندوز IMAPI2، در بقیه xorriso)
  - `ai_upscale.rs` / `cpu_sr.rs` / `audio_sr.rs` — Real-ESRGAN (GPU/CPU)، گسترش پهنای باند صوت
  - `mkv_tracks.rs` — حفظ/افزودن چند ترک صوتی و زیرنویس در MKV
  - `plugins.rs` / `sidecar.rs` — ابزارهای همراه/دانلودی با مدیریت نسخه
  - `cpu.rs` — تشخیص مجموعه‌دستورهای CPU با `open-cpu` (راهنمای سرعت و انتخاب `-preset` برای x264)

## قواعد ثابت

- **هیچ دور زدنی برای حفاظت کپی** (CSS/AACS و غیره) انجام نمی‌شود. فقط دیسک‌های بدون حفاظت.
- **Dolby Vision / Atmos / IMAX / 4DX به‌صورت جدید ساخته نمی‌شوند** (دارای مجوز)؛ فقط حفظ با کپی جریان و قالب‌های پایین‌تر سازگار.
- **MQA پشتیبانی نمی‌شود** (حق ثبت اختراع/اسرار تجاری). خروجی با وضوح بالا مسیر قالب‌های باز `aon-co-jp/open-mqa` را دنبال می‌کند.
- **هنگام ساخت DSD، PCM هم‌زمان ساخته نمی‌شود** (روی سخت‌افزار بدون DSD، پخش‌کننده خودکار به PCM تبدیل می‌کند). WAV از نوع DoP دادهٔ DSD است و مجاز است.
- مدولاسیون DSD **به‌صورت ترتیبی برای هر کانال (کاملاً یکسان در سطح بیت)** باقی می‌ماند؛ مدولاسیون موازی قطعه‌ای طبق اندازه‌گیری SNR را از بین می‌برد و کنار گذاشته شد.
- قابلیت‌های «هوش مصنوعی» صادقانه توصیف می‌شوند: برش خودکار بر اساس سکوت و وضوح/نرخ فریم «بهینه‌شده با هوش مصنوعی» اکتشافی‌اند؛ گسترش پهنای باند صوت سنتز است.
- Full HD روی DVD خارج از استاندارد DVD-Video است؛ پخش‌کننده‌های خانگی وضوح را خودکار کاهش نمی‌دهند. رابط کاربری این هشدار را نگه می‌دارد (کاربر ترکیب DVD-Video + فایل Full HD را نپذیرفت).
- زبان‌های مستندات: ژاپنی مرجع است؛ `README/`، `CLAUDE/`، `PORTING/` شامل انگلیسی، چینی ساده، چینی سنتی (تایوان)، کره‌ای، آلمانی، فرانسوی، روسی، اوکراینی، فارسی (ایران، پسوند فایل `.iran(Perusha)`) و عربی هستند (CLAUDE/PORTING به‌صورت خلاصه).

## قواعد راستی‌آزمایی

- موفقیت CI دلیل کارکرد نیست. پیش از اعلام اتمام، واقعاً بررسی کنید: `npm run lint` (قاعدهٔ `no-undef` در eslint)، آزمایش رابط کاربری در مرورگر با APIهای شبیه‌سازی‌شدهٔ Tauri، آزمون‌های Rust (`cargo test --lib -- --test-threads=1`) و در صورت امکان E2E با فایل‌ها / سخت‌افزار واقعی.
- آنچه بررسی نشده را صادقانه ذکر کنید.

## انتشار

push کردن برچسب `v*` فایل `.github/workflows/release.yml` را اجرا می‌کند که نصب‌کننده‌های ویندوز/macOS/لینوکس/اندروید را می‌سازد و در GitHub Releases منتشر می‌کند.

## وضعیت فعلی (2026-09-23)

برش بازه‌ای که از بخش 8 قابل استفاده نبود اصلاح شد؛ هنگام ساخت DSD دیگر PCM ساخته نمی‌شود؛ برش به‌صورت بله/خیر انحصاری «بر اساس اندازه / بر اساس زمان» (پیش‌فرض اندازه) بازطراحی شد و «پر کردن دیسک» و «برش سکوت با هوش مصنوعی» به چک‌باکس‌های پس‌پردازش تبدیل شدند؛
سقف استانداردهای پخش (CD / DVD-Video / DVD-Audio / Blu-ray / UHD Blu-ray / فقط رایانه) برای بیشینهٔ کیلوهرتز، عمق بیت و نرخ بیت افزوده شد. آزمون E2E با فایل‌های واقعی هنوز انجام نشده است.
