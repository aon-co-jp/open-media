یک برنامهٔ گرافیکی چندسکویی (Rust + Tauri) برای رایت CD/DVD/Blu-ray و تبدیل صوت/تصویر.
یک پایگاه کد واحد؛ فقط نصب‌کننده‌ها برای هر سیستم‌عامل متفاوت‌اند.

## قابلیت‌ها

- **ورودی/خروجی**: انتخاب چند فایل منبع (صوت/ویدئو/PDF) و یک پوشهٔ خروجی. تبدیل، ساخت ایمیج ISO و رایت دیسک را می‌توان هم‌زمان با چک‌باکس انتخاب کرد
  (چند قالب، چند فایل و چند نوع دیسک به‌صورت ناهم‌گام و موازی اجرا می‌شوند).
- **صوت**: MP3 / WAV / FLAC / AAC / OGG / **Opus** / **AC-3 / E-AC-3 (5.1 تا 7.1)** /
  **DSD64·128·256·512·1024 (DSF)**. چون ffmpeg نمی‌تواند DSD بنویسد، مدولاسیون دلتا-سیگما PCM→۱ بیتی
  (مرتبهٔ ۵، یک رشته برای هر کانال) و نوشتن DSF به زبان Rust پیاده‌سازی و با رفت‌وبرگشت از طریق رمزگشای DSF در ffmpeg تأیید شده است.
- **ویدئو**: MP4 / MKV / AVI / MOV / WebM / **AV1** (ترجیحاً libsvtav1، در غیر این صورت libaom) /
  **HEVC ده‌بیتی (HDR10)** / **کپی بی‌اتلاف جریان** (Dolby Vision، Atmos و صدای فراگیر 5.1/7.1 را حفظ می‌کند).
  وضوح (از 720×480 تا 8K، PAL، دلخواه، «بهینه‌سازی با هوش مصنوعی») و نرخ فریم (24/30/60/120، دلخواه) قابل انتخاب است؛
  گزینه‌ها بر اساس جهت تبدیل محدود می‌شوند (BD→DVD: وضوح استاندارد DVD یا Full HD؛ DVD→BD: Full HD یا 4K).
- **PCM با وضوح بالا (برای DACهای R-2R / چندبیتی)**: WAV با 352.8 کیلوهرتز / 384 کیلوهرتز (24 و 32 بیت) و 705.6 کیلوهرتز / 768 کیلوهرتز (32 بیت)،
  با بهترین بازنمونه‌گیر موجود (soxr، وگرنه تنظیم دقیق swresample) و دیتر TPDF. SNR اندازه‌گیری‌شده در برابر یک سینوسی مرجع دقیق:
  352.8 کیلوهرتز/24 بیت = 141.2 دسی‌بل، 384 کیلوهرتز/32 بیت = 150.2 دسی‌بل.
  هنگام ساخت DSD، PCM هم‌زمان ساخته نمی‌شود (روی سخت‌افزار بدون DSD، پخش‌کننده خودکار DSD را به PCM تبدیل می‌کند و نسخهٔ PCM فقط فضا را هدر می‌دهد).
  SNR رفت‌وبرگشت DSD: DSD64 = 99.6 دسی‌بل، DSD128 = 132.4 دسی‌بل.
- **ابرتفکیک با هوش مصنوعی (ویدئو)**: Real-ESRGAN (MIT) به‌صورت افزونهٔ درخواستی (مثلاً DVD→4K). اگر دستگاه Vulkan کار کند از GPU (NCNN-Vulkan) استفاده می‌کند،
  وگرنه خودکار به **پیاده‌سازی CPU اختصاصی ما با Rust** می‌رود (AVX2+FMA خودکار؛ PSNR خروجی 42.0 دسی‌بل نسبت به پیاده‌سازی رسمی GPU).
- **گسترش پهنای باند با هوش مصنوعی (آزمایشی)**: فرکانس‌های بالای ازدست‌رفتهٔ صوت با پهنای باند محدود را با یک مدل آموزش‌دیده می‌سازد (LavaSR، Apache-2.0، اجرا با tract خالص Rust، حدود 56 مگابایت در اولین استفاده).
  **باند موجود هرگز تغییر نمی‌کند** و فرکانس‌های تولیدشده با برون‌یابی پوش ورودی محدود می‌شوند (خروجی خام مدل موسیقی را بدتر می‌کرد، به همین دلیل این طراحی).
  اندازه‌گیری (موسیقی محدودشده در 8/12 کیلوهرتز): LSD در باند دارای مرجع 3.4→1.5 و 2.7→1.6، باند پایین بدون تغییر. این سنتز است نه بازسازی، و برای منابع بدون محدودیت باند کاری انجام نمی‌دهد.
- **کاهش نویز با هوش مصنوعی**: یک شبکهٔ عصبی واقعی آموزش‌دیده (RNNoise) همراه برنامه است و با مدل واقعی تأیید شده. عمدتاً روی گفتار آموزش دیده و اثرش روی موسیقی اندک است.
- **نرخ بیت / ظرفیت**: ثابت، خودکار بر اساس ظرفیت دیسک، و حالت «بیشترین کیفیت» (اگر قالبی انتخاب نشود، WAV بی‌اتلاف + ISO).
  نرخ بیت خودکار به نرخ بیت منبع محدود می‌شود؛ خروجی‌های فقط‌صوتی به‌درستی از `-b:a` استفاده می‌کنند.
- **برش دادهٔ منبع**: به پرسش‌های «برش بر اساس اندازه؟» و «برش بر اساس زمان؟» با بله/خیر پاسخ داده می‌شود (انحصاری؛ دقیقاً یکی «بله»؛ پیش‌فرض اندازه).
  پس‌پردازش با چک‌باکس: «پر کردن دیسک» (CD / DVD یک تا دو لایه / Blu-ray یک تا چهار لایه) و «برش خودکار با هوش مصنوعی» (تشخیص سکوت).
- **سقف استانداردهای پخش**: بیشینهٔ کیلوهرتز، عمق بیت و نرخ بیت CD / DVD-Video / DVD-Audio / Blu-ray / Ultra HD Blu-ray / فقط رایانه را نشان می‌دهد
  و مطابق استاندارد انتخاب‌شده تبدیل می‌کند (منابعی که زیر سقف‌اند دست‌نخورده می‌مانند؛ بدون افزایش نرخ نمونه‌برداری).
- **ویرایش**: برش چند بازه (فایل را در بخش 8 انتخاب کنید و با پیش‌نمایش ویدئو/صوت بازه‌ها را تعیین کنید)، به‌هم‌پیوستن فایل‌ها،
  تقسیم به بخش‌های مساوی یا بر اساس اندازه (باقی‌مانده خودکار برای پر کردن دیسک تنظیم می‌شود).
- **PDF**: تصاویر دوصفحه‌ای (صحافی راست/چپ، تا 4K) و تبدیل گروهی جهت صحافی (معکوس کردن ترتیب صفحات).
- **رایت (ویندوز)**: درایوهای نوری را خودکار شناسایی می‌کند، با IMAPI2 فایل ISO می‌سازد (نام فایل‌های ژاپنی حفظ می‌شود) و رایت می‌کند.
  روی سخت‌افزار واقعی (درایو BD-RE + CD-R) تأیید شده: ویدئوی 3.5 ساعته → صوتی که CD را پر می‌کند → ISO → رایت موفق.
- **سایر**: بررسی خودکار به‌روزرسانی هنگام اجرا (پنجرهٔ دوزبانه)؛ افزونه‌های نسخه‌دار rs-ffmpeg / rs-xorriso (نسخهٔ یکسان بازنویسی نمی‌شود).

## پشتیبانی‌نشده / محدودیت‌ها (افشای صادقانه)

- **دور زدن حفاظت کپی (CSS/AACS و غیره) پیاده‌سازی نشده است** (ممکن است غیرقانونی باشد). فقط دیسک‌های بدون حفاظت.
- **ساخت جدید Dolby Vision / Atmos / Dolby Cinema / IMAX / 4DX ممکن نیست** (قالب‌های دارای مجوز). فقط حفظ (کپی جریان) و قالب‌های پایین‌تر سازگار.
- **ابرتفکیک ویدئو با هوش مصنوعی (Real-ESRGAN) بسیار کند است — فقط برای کلیپ‌های کوتاه** (برای هر فریم 720×480: مدل سریع حدود 1.2 ثانیه روی CPU سی‌ودو رشته‌ای با AVX2، حدود 4.6 ثانیه روی GPU مدل GT 730؛
  مدل باکیفیت حدود 110 ثانیه روی GT 730). نسخهٔ CPU فقط مدل سریع را پشتیبانی می‌کند. **گسترش پهنای باند صوت با هوش مصنوعی آزمایشی است** (سنتز است و کیفیت شنیداری را تضمین نمی‌کند).
  گزینه‌های وضوح/نرخ فریم «بهینه‌سازی با هوش مصنوعی» اکتشافی‌های ساده‌اند، نه ابرتفکیک.
- فایل‌های DSD بسیار بزرگ‌اند (برای هر دقیقهٔ استریو: DSD64 ≈ 42 مگابایت … DSD1024 ≈ 678 مگابایت) و فایل DSF هستند، نه دیسک Super Audio CD.
- Full HD روی DVD خارج از استاندارد DVD-Video (حداکثر 720×480/576) است؛ پخش‌کننده‌های خانگی DVD وضوح را خودکار کاهش نمی‌دهند، بنابراین ممکن است پخش نشود.
- رایت در لینوکس/macOS به xorriso اصلی نیاز دارد (همراه نیست). دیسک‌ها به‌صورت دیسک داده رایت می‌شوند (CD صوتی / CD-DA پشتیبانی نمی‌شود).
- iOS پشتیبانی نمی‌شود (دستگاه آزمایشی در دسترس نیست).

## وابستگی‌های خارجی هنگام اجرا

نصب‌کننده‌های ویندوز/لینوکس شامل ffmpeg/ffprobe و rs-ffmpeg/rs-xorriso هستند (نگاه کنید به `src-tauri/src/engine/sidecar.rs` و `plugins.rs`)؛
در نبود آن‌ها از ابزارهای موجود در `PATH` استفاده می‌شود. در macOS، ffmpeg و xorriso اصلی همراه نیستند.

## دانلود / نصب‌کننده‌ها

ویندوز (.msi/.exe)، macOS (.dmg، Intel/Apple Silicon)، لینوکس (.deb/.rpm/.AppImage) و اندروید (APK عمومی) در
[GitHub Releases](https://github.com/aon-co-jp/make-disk/releases/latest) منتشر می‌شوند. push کردن برچسب `v*` همهٔ سکوها را از طریق
`.github/workflows/release.yml` می‌سازد. صفحهٔ معرفی: <https://easy-web.tokyo/make-disk/>
