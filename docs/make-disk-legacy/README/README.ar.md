تطبيق رسومي متعدد المنصات (Rust + Tauri) لنسخ أقراص CD/DVD/Blu-ray وتحويل الصوت والفيديو.
قاعدة شيفرة واحدة؛ ولا تختلف إلا برامج التثبيت بحسب نظام التشغيل.

## الميزات

- **الإدخال/الإخراج**: اختيار عدة ملفات مصدر (صوت/فيديو/PDF) ومجلد إخراج. يمكن تحديد التحويل وإنشاء صورة ISO ونسخ القرص معًا بمربعات الاختيار
  (تُنفَّذ الصيغ والملفات وأنواع الأقراص المتعددة بشكل غير متزامن وبالتوازي).
- **الصوت**: MP3 / WAV / FLAC / AAC / OGG / **Opus** / **AC-3 / E-AC-3 (5.1 إلى 7.1)** /
  **DSD64·128·256·512·1024 (DSF)**. لأن ffmpeg لا يستطيع كتابة DSD، نُفِّذ تعديل دلتا-سيغما من PCM إلى بت واحد
  (من الرتبة الخامسة، خيط لكل قناة) وكتابة DSF بلغة Rust، وتم التحقق منهما بالذهاب والإياب عبر مفكك DSF في ffmpeg.
- **الفيديو**: MP4 / MKV / AVI / MOV / WebM / **AV1** (يُفضَّل libsvtav1، وإلا libaom) /
  **HEVC بعمق 10 بت (HDR10)** / **نسخ التدفق دون فقد** (يحتفظ بـ Dolby Vision وAtmos والصوت المحيطي 5.1/7.1).
  يمكن اختيار الدقة (من 720×480 حتى 8K، وPAL، ومخصصة، و«محسّنة بالذكاء الاصطناعي») ومعدل الإطارات (24/30/60/120، ومخصص)؛
  وتُضيَّق الخيارات حسب اتجاه التحويل (BD→DVD: دقة DVD القياسية أو Full HD؛ DVD→BD: Full HD أو 4K).
- **PCM عالي الدقة (لمحولات R-2R / متعددة البتات)**: ملفات WAV بتردد 352.8 كيلوهرتز / 384 كيلوهرتز (24 و32 بت) و705.6 كيلوهرتز / 768 كيلوهرتز (32 بت)،
  بأفضل معيد تشكيل عينات متاح (soxr، وإلا إعداد swresample عالي الدقة) مع اهتزاز TPDF. نسبة الإشارة إلى الضجيج المقيسة مقابل موجة جيبية مرجعية دقيقة:
  352.8 كيلوهرتز/24 بت = 141.2 ديسيبل، و384 كيلوهرتز/32 بت = 150.2 ديسيبل.
  عند إنشاء DSD لا يُنشأ PCM معه (على العتاد الذي لا يدعم DSD يحوّل المشغّل DSD إلى PCM تلقائيًا، فتكون نسخة PCM مجرد هدر للمساحة).
  نسبة الإشارة إلى الضجيج المقيسة لـ DSD ذهابًا وإيابًا: DSD64 = 99.6 ديسيبل، DSD128 = 132.4 ديسيبل.
- **الدقة الفائقة بالذكاء الاصطناعي (فيديو)**: Real-ESRGAN (MIT) كإضافة تُحمَّل عند الطلب (مثل DVD→4K). يستخدم وحدة GPU (NCNN-Vulkan) إذا عمل جهاز Vulkan،
  وإلا ينتقل تلقائيًا إلى **تنفيذنا الخاص على المعالج بلغة Rust** (يستخدم AVX2+FMA تلقائيًا؛ PSNR للإخراج 42.0 ديسيبل مقارنة بالتنفيذ الرسمي على GPU).
- **توسيع النطاق الترددي بالذكاء الاصطناعي (تجريبي)**: يضيف الترددات العالية المفقودة للصوت محدود النطاق بنموذج مدرَّب (LavaSR، Apache-2.0، يعمل عبر tract بلغة Rust الخالصة، نحو 56 ميغابايت عند أول استخدام).
  **لا يُغيَّر النطاق الموجود أبدًا**، وتُقيَّد الترددات المولَّدة باستقراء غلاف الإدخال (لأن الإخراج الخام للنموذج أساء إلى الموسيقى، ولذلك هذا التصميم).
  القياس (موسيقى محدودة عند 8/12 كيلوهرتز): LSD في النطاق الذي له مرجع 3.4→1.5 و2.7→1.6، والنطاق المنخفض دون تغيير. إنه توليف وليس استعادة، ولا يفعل شيئًا للمصادر غير المحدودة النطاق.
- **إزالة الضجيج بالذكاء الاصطناعي**: يتضمن شبكة عصبية حقيقية مدرَّبة (RNNoise) تم التحقق منها بالنموذج الحقيقي. دُرِّبت أساسًا على الكلام، لذا أثرها على الموسيقى محدود.
- **معدل البت / السعة**: ثابت، أو تلقائي حسب سعة القرص، ووضع «أعلى جودة» (WAV دون فقد + ISO إذا لم تُختر صيغة).
  يُحدّ معدل البت التلقائي بمعدل بت المصدر، وتستخدم مخرجات الصوت فقط `-b:a` بشكل صحيح.
- **قص البيانات المصدر**: يُجاب عن «القص حسب الحجم؟» و«القص حسب الوقت؟» بنعم/لا (متنافيان، واحد فقط «نعم» دائمًا؛ الافتراضي الحجم).
  معالجة لاحقة بمربعات اختيار: «ملء القرص» (CD / DVD طبقة أو طبقتان / Blu-ray من طبقة إلى أربع) و«القص التلقائي بالذكاء الاصطناعي» (اكتشاف الصمت).
- **حدود معايير التشغيل**: يعرض الحد الأقصى للكيلوهرتز وعمق البت ومعدل البت لكل من CD / DVD-Video / DVD-Audio / Blu-ray / Ultra HD Blu-ray / الحاسوب فقط،
  ويحوّل ضمن المعيار المختار (تبقى المصادر التي دون الحد كما هي؛ دون رفع معدل العينات).
- **التحرير**: قص عدة مقاطع (اختر الملف في القسم 8 وحدّد المقاطع أثناء معاينة الفيديو/الصوت)، ودمج الملفات،
  والتقسيم إلى أجزاء متساوية أو حسب الحجم (يُضبط الجزء المتبقي تلقائيًا لملء القرص).
- **PDF**: صور الصفحتين المتقابلتين (تجليد يمين/يسار، حتى 4K) وتحويل اتجاه التجليد دفعة واحدة (عكس ترتيب الصفحات).
- **النسخ (ويندوز)**: يكتشف محركات الأقراص الضوئية تلقائيًا، وينشئ ISO عبر IMAPI2 (مع الحفاظ على أسماء الملفات اليابانية) وينسخها.
  تم التحقق على عتاد حقيقي (محرك BD-RE + CD-R): فيديو مدته 3.5 ساعات → صوت يملأ القرص → ISO → نسخ ناجح.
- **أخرى**: فحص تلقائي للتحديثات عند التشغيل (نافذة ثنائية اللغة)؛ إضافات rs-ffmpeg / rs-xorriso بإدارة إصدارات (لا يُستبدل الإصدار المطابق).

## غير مدعوم / القيود (إفصاح صريح)

- **لم يُنفَّذ تجاوز الحماية من النسخ (CSS/AACS وغيرها)** (قد يكون غير قانوني). الأقراص غير المحمية فقط.
- **لا يمكن إنشاء Dolby Vision / Atmos / Dolby Cinema / IMAX / 4DX من جديد** (صيغ مرخّصة). فقط الحفظ (نسخ التدفق) والصيغ الأدنى المتوافقة.
- **الدقة الفائقة للفيديو بالذكاء الاصطناعي (Real-ESRGAN) بطيئة جدًا — للمقاطع القصيرة فقط** (لكل إطار 720×480: النموذج السريع نحو 1.2 ثانية على معالج AVX2 بـ 32 خيطًا، ونحو 4.6 ثانية على GPU من طراز GT 730؛
  والنموذج عالي الجودة نحو 110 ثوانٍ على GT 730). نسخة المعالج تدعم النموذج السريع فقط. **توسيع النطاق الصوتي بالذكاء الاصطناعي تجريبي** (توليف، دون ضمان للجودة المسموعة).
  خيارات الدقة/معدل الإطارات «المحسّنة بالذكاء الاصطناعي» مجرد قواعد تقريبية بسيطة، وليست دقة فائقة.
- ملفات DSD ضخمة جدًا (لكل دقيقة ستيريو: DSD64 ≈ 42 ميغابايت … DSD1024 ≈ 678 ميغابايت) وهي ملفات DSF وليست قرص Super Audio CD.
- دقة Full HD على DVD خارج معيار DVD-Video (الحد الأقصى 720×480/576)؛ ومشغلات DVD المنزلية لا تخفض الدقة تلقائيًا، لذا قد يتعذر التشغيل.
- النسخ على لينكس/macOS يتطلب xorriso الأصلي (غير مضمَّن). تُنسخ الأقراص كأقراص بيانات (نسخ أقراص الصوت CD-DA غير مدعوم).
- نظام iOS غير مدعوم (لا يوجد جهاز للاختبار).

## التبعيات الخارجية أثناء التشغيل

تتضمن برامج التثبيت لويندوز/لينكس ffmpeg/ffprobe وrs-ffmpeg/rs-xorriso (انظر `src-tauri/src/engine/sidecar.rs` و`plugins.rs`)؛
وإن لم توجد تُستخدم الأدوات الموجودة في `PATH`. في macOS لا يُضمَّن ffmpeg ولا xorriso الأصلي.

`.github/workflows/release.yml`. صفحة التعريف: <https://easy-web.tokyo/make-disk/>
