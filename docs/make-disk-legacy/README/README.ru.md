# make-disk

**Языки**: [日本語](../README.md) | [English](README.en.md) | [简体中文](README.zh-CN.md) | [繁體中文(台灣)](README.zh-TW.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | Русский | [Українська](README.uk.md) | [فارسی](README.iran%28Perusha%29.md) | [العربية](README.ar.md)

Кроссплатформенное GUI-приложение (Rust + Tauri) для записи CD/DVD/Blu-ray и конвертации аудио/видео.
Единая кодовая база; различаются только установщики для разных ОС.

## Возможности

- **Ввод/вывод**: выбор нескольких исходных файлов (аудио/видео/PDF) и папки вывода. Конвертацию, создание ISO-образа и запись диска
  можно отметить одновременно (несколько форматов, файлов и типов дисков обрабатываются асинхронно и параллельно).
- **Аудио**: MP3 / WAV / FLAC / AAC / OGG / **Opus** / **AC-3 / E-AC-3 (5.1–7.1)** /
  **DSD64·128·256·512·1024 (DSF)**. ffmpeg не умеет записывать DSD, поэтому дельта-сигма-модуляция PCM→1 бит
  (5-го порядка, поток на канал) и запись DSF реализованы на Rust и проверены круговым прогоном через DSF-декодер ffmpeg.
- **Видео**: MP4 / MKV / AVI / MOV / WebM / **AV1** (предпочтительно libsvtav1, иначе libaom) /
  **HEVC 10 бит (HDR10)** / **копирование потока без потерь** (сохраняет Dolby Vision, Atmos, объёмный звук 5.1/7.1).
  Разрешение (от 720×480 до 8K, PAL, произвольное, «ИИ-оптимизация») и частота кадров (24/30/60/120, произвольная) задаются вручную;
  варианты сужаются по направлению конвертации (BD→DVD: стандартное разрешение DVD или Full HD; DVD→BD: Full HD или 4K).
- **PCM высокого разрешения (для R-2R / многобитных ЦАП)**: WAV 352,8 кГц / 384 кГц (24 и 32 бит) и 705,6 кГц / 768 кГц (32 бит)
  с лучшим доступным ресемплером (soxr, иначе высокоточная настройка swresample) и TPDF-дизерингом. Измеренное SNR относительно точной эталонной синусоиды:
  352,8 кГц/24 бит = 141,2 дБ, 384 кГц/32 бит = 150,2 дБ.
  При создании DSD PCM одновременно не создаётся (на оборудовании без DSD плеер сам автоматически преобразует DSD в PCM, так что PCM-версия лишь занимает место).
  Измеренное SNR кругового прогона DSD: DSD64 = 99,6 дБ, DSD128 = 132,4 дБ.
- **ИИ-сверхразрешение (видео)**: Real-ESRGAN (MIT) как подгружаемый по требованию плагин (например, DVD→4K). Использует GPU (NCNN-Vulkan), если работает устройство Vulkan,
  иначе автоматически переключается на нашу **собственную CPU-реализацию на Rust** (AVX2+FMA автоматически; PSNR вывода 42,0 дБ относительно официальной GPU-реализации).
- **ИИ-расширение полосы (экспериментально)**: достраивает недостающие высокие частоты у аудио с ограниченной полосой с помощью обученной модели (LavaSR, Apache-2.0, выполняется через tract на чистом Rust, ~56 МБ при первом запуске).
  **Существующая полоса никогда не изменяется**; сгенерированные высокие ограничены экстраполяцией огибающей входа (сырой вывод модели ухудшал музыку, отсюда такая схема).
  Измерения (музыка, ограниченная 8/12 кГц): LSD в полосе с эталоном 3,4→1,5 и 2,7→1,6, низкие без изменений. Это синтез, а не восстановление; источники без ограничения полосы не обрабатываются.
- **ИИ-шумоподавление**: встроена настоящая обученная нейросеть (RNNoise), проверенная на реальной модели. Обучена в основном на речи, поэтому на музыке эффект скромный.
- **Битрейт / ёмкость**: фиксированный, автоматический по ёмкости диска и режим «максимальное качество» (WAV без потерь + ISO, если формат не выбран).
  Автоматический битрейт ограничен битрейтом источника; для чисто аудио-вывода корректно используется `-b:a`.
- **Обрезка источника**: на вопросы «Обрезать по размеру?» и «Обрезать по времени?» отвечают ДА/НЕТ (взаимоисключающие, ровно один ДА; по умолчанию размер).
  Постобработка флажками: «Заполнить диск» (CD / DVD 1–2 слоя / Blu-ray 1–4 слоя) и «ИИ-автообрезка» (детекция тишины).
- **Пределы стандартов воспроизведения**: показывает максимальные кГц, разрядность и битрейт для CD / DVD-Video / DVD-Audio / Blu-ray / Ultra HD Blu-ray / только ПК
  и конвертирует в рамках выбранного стандарта (источники ниже предела не меняются; без передискретизации вверх).
- **Редактирование**: вырезание нескольких участков (выберите файл в разделе 8 и задайте участки с предпросмотром видео/аудио), объединение файлов,
  разбиение на равные части или по размеру (остаток автоматически подгоняется под заполнение диска).
- **PDF**: изображения разворотов (переплёт справа/слева, до 4K) и пакетная смена направления переплёта (обратный порядок страниц).
- **Запись (Windows)**: автоматически находит оптические приводы, создаёт ISO через IMAPI2 (сохраняет японские имена файлов) и записывает.
  Проверено на реальном оборудовании (привод BD-RE + CD-R): видео 3,5 ч → аудио, заполняющее CD → ISO → запись успешна.
- **Прочее**: автоматическая проверка обновлений при запуске (двуязычный диалог); версионируемые плагины rs-ffmpeg / rs-xorriso (одинаковая версия не перезаписывается).

## Не поддерживается / ограничения (честно)

- **Обход защиты от копирования (CSS/AACS и т. п.) не реализован** (может быть незаконным). Только незащищённые диски.
- **Создавать Dolby Vision / Atmos / Dolby Cinema / IMAX / 4DX нельзя** (лицензируемые форматы). Только сохранение (копирование потока) и совместимые младшие форматы.
- **ИИ-сверхразрешение видео (Real-ESRGAN) очень медленное — только для коротких клипов** (на кадр 720×480: быстрая модель ~1,2 с на 32-поточном CPU с AVX2, ~4,6 с на GPU GT 730;
  качественная модель ~110 с на GT 730). CPU-версия поддерживает только быструю модель. **ИИ-расширение полосы аудио — экспериментальное** (синтез, качество на слух не гарантируется).
  Параметры разрешения/FPS с пометкой «ИИ-оптимизация» — простые эвристики, а не сверхразрешение.
- Файлы DSD огромны (на стереоминуту: DSD64 ≈ 42 МБ … DSD1024 ≈ 678 МБ) и являются файлами DSF, а не диском Super Audio CD.
- Full HD на DVD выходит за рамки стандарта DVD-Video (макс. 720×480/576); бытовые DVD-плееры не снижают разрешение автоматически, поэтому воспроизведение может не работать.
- Запись в Linux/macOS требует оригинального xorriso (не входит в комплект). Диски записываются как диски с данными (аудио-CD / CD-DA не поддерживается).
- iOS не поддерживается (нет тестового устройства).

## Внешние зависимости во время работы

Установщики для Windows/Linux включают ffmpeg/ffprobe и rs-ffmpeg/rs-xorriso (см. `src-tauri/src/engine/sidecar.rs` и `plugins.rs`);
если их нет, используются инструменты из `PATH`. В macOS ffmpeg и оригинальный xorriso не входят в комплект.

## Разработка

```bash
npm install
npm run tauri dev
cd src-tauri && cargo test --lib -- --test-threads=1
```

## Загрузки / установщики

Windows (.msi/.exe), macOS (.dmg, Intel/Apple Silicon), Linux (.deb/.rpm/.AppImage) и Android (универсальный APK) доступны на
[GitHub Releases](https://github.com/aon-co-jp/make-disk/releases/latest). Push тега `v*` собирает все платформы через
`.github/workflows/release.yml`. Страница проекта: <https://easy-web.tokyo/make-disk/>
