# make-disk

**Мови**: [日本語](../README.md) | [English](README.en.md) | [简体中文](README.zh-CN.md) | [繁體中文(台灣)](README.zh-TW.md) | [한국어](README.ko.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [Русский](README.ru.md) | Українська | [فارسی](README.iran%28Perusha%29.md) | [العربية](README.ar.md)

Кросплатформний GUI-застосунок (Rust + Tauri) для запису CD/DVD/Blu-ray і конвертації аудіо/відео.
Єдина кодова база; відрізняються лише інсталятори для різних ОС.

## Можливості

- **Введення/виведення**: вибір кількох вихідних файлів (аудіо/відео/PDF) і теки виведення. Конвертацію, створення ISO-образу та запис диска
  можна позначити одночасно (кілька форматів, файлів і типів дисків обробляються асинхронно й паралельно).
- **Аудіо**: MP3 / WAV / FLAC / AAC / OGG / **Opus** / **AC-3 / E-AC-3 (5.1–7.1)** /
  **DSD64·128·256·512·1024 (DSF)**. ffmpeg не вміє записувати DSD, тому дельта-сигма-модуляцію PCM→1 біт
  (5-го порядку, потік на канал) і запис DSF реалізовано на Rust та перевірено круговим прогоном через DSF-декодер ffmpeg.
- **Відео**: MP4 / MKV / AVI / MOV / WebM / **AV1** (переважно libsvtav1, інакше libaom) /
  **HEVC 10 біт (HDR10)** / **копіювання потоку без втрат** (зберігає Dolby Vision, Atmos, об'ємний звук 5.1/7.1).
  Роздільна здатність (від 720×480 до 8K, PAL, довільна, «ШІ-оптимізація») і частота кадрів (24/30/60/120, довільна) задаються вручну;
  варіанти звужуються за напрямом конвертації (BD→DVD: стандартна роздільна здатність DVD або Full HD; DVD→BD: Full HD або 4K).
- **PCM високої роздільності (для R-2R / багатобітних ЦАП)**: WAV 352,8 кГц / 384 кГц (24 і 32 біт) та 705,6 кГц / 768 кГц (32 біт)
  з найкращим доступним ресемплером (soxr, інакше високоточне налаштування swresample) і TPDF-дизерингом. Виміряне SNR відносно точної еталонної синусоїди:
  352,8 кГц/24 біт = 141,2 дБ, 384 кГц/32 біт = 150,2 дБ.
  Під час створення DSD PCM одночасно не створюється (на обладнанні без DSD програвач сам автоматично перетворює DSD на PCM, тож PCM-версія лише займає місце).
  Виміряне SNR кругового прогону DSD: DSD64 = 99,6 дБ, DSD128 = 132,4 дБ.
- **ШІ-надроздільність (відео)**: Real-ESRGAN (MIT) як плагін, що завантажується на вимогу (наприклад, DVD→4K). Використовує GPU (NCNN-Vulkan), якщо працює пристрій Vulkan,
  інакше автоматично перемикається на нашу **власну CPU-реалізацію на Rust** (AVX2+FMA автоматично; PSNR виводу 42,0 дБ відносно офіційної GPU-реалізації).
- **ШІ-розширення смуги (експериментально)**: добудовує відсутні високі частоти в аудіо з обмеженою смугою за допомогою навченої моделі (LavaSR, Apache-2.0, виконується через tract на чистому Rust, ~56 МБ під час першого запуску).
  **Наявна смуга ніколи не змінюється**; згенеровані високі обмежено екстраполяцією обвідної входу (сирий вивід моделі погіршував музику, звідси така схема).
  Вимірювання (музика, обмежена 8/12 кГц): LSD у смузі з еталоном 3,4→1,5 і 2,7→1,6, низькі без змін. Це синтез, а не відновлення; джерела без обмеження смуги не обробляються.
- **ШІ-шумозаглушення**: вбудовано справжню навчену нейромережу (RNNoise), перевірену на реальній моделі. Навчена переважно на мовленні, тому на музиці ефект скромний.
- **Бітрейт / ємність**: фіксований, автоматичний за ємністю диска та режим «максимальна якість» (WAV без втрат + ISO, якщо формат не вибрано).
  Автоматичний бітрейт обмежено бітрейтом джерела; для суто аудіовиводу коректно використовується `-b:a`.
- **Обрізання джерела**: на запитання «Обрізати за розміром?» і «Обрізати за часом?» відповідають ТАК/НІ (взаємовиключні, рівно одне ТАК; за замовчуванням розмір).
  Постобробка прапорцями: «Заповнити диск» (CD / DVD 1–2 шари / Blu-ray 1–4 шари) і «ШІ-автообрізання» (виявлення тиші).
- **Межі стандартів відтворення**: показує максимальні кГц, розрядність і бітрейт для CD / DVD-Video / DVD-Audio / Blu-ray / Ultra HD Blu-ray / лише ПК
  і конвертує в межах вибраного стандарту (джерела нижче межі не змінюються; без передискретизації вгору).
- **Редагування**: вирізання кількох ділянок (виберіть файл у розділі 8 і задайте ділянки з попереднім переглядом відео/аудіо), об'єднання файлів,
  поділ на рівні частини або за розміром (залишок автоматично підганяється під заповнення диска).
- **PDF**: зображення розворотів (палітурка справа/зліва, до 4K) і пакетна зміна напрямку палітурки (зворотний порядок сторінок).
- **Запис (Windows)**: автоматично знаходить оптичні приводи, створює ISO через IMAPI2 (зберігає японські імена файлів) і записує.
  Перевірено на реальному обладнанні (привід BD-RE + CD-R): відео 3,5 год → аудіо, що заповнює CD → ISO → запис успішний.
- **Інше**: автоматична перевірка оновлень під час запуску (двомовний діалог); версіоновані плагіни rs-ffmpeg / rs-xorriso (однакова версія не перезаписується).

## Не підтримується / обмеження (чесно)

- **Обхід захисту від копіювання (CSS/AACS тощо) не реалізовано** (може бути незаконним). Лише незахищені диски.
- **Створювати Dolby Vision / Atmos / Dolby Cinema / IMAX / 4DX неможливо** (ліцензовані формати). Лише збереження (копіювання потоку) і сумісні молодші формати.
- **ШІ-надроздільність відео (Real-ESRGAN) дуже повільна — лише для коротких кліпів** (на кадр 720×480: швидка модель ~1,2 с на 32-потоковому CPU з AVX2, ~4,6 с на GPU GT 730;
  якісна модель ~110 с на GT 730). CPU-версія підтримує лише швидку модель. **ШІ-розширення смуги аудіо — експериментальне** (синтез, якість на слух не гарантується).
  Параметри роздільності/FPS з позначкою «ШІ-оптимізація» — прості евристики, а не надроздільність.
- Файли DSD величезні (на стереохвилину: DSD64 ≈ 42 МБ … DSD1024 ≈ 678 МБ) і є файлами DSF, а не диском Super Audio CD.
- Full HD на DVD виходить за межі стандарту DVD-Video (макс. 720×480/576); побутові DVD-програвачі не знижують роздільну здатність автоматично, тож відтворення може не працювати.
- Запис у Linux/macOS потребує оригінального xorriso (не входить до комплекту). Диски записуються як диски з даними (аудіо-CD / CD-DA не підтримується).
- iOS не підтримується (немає тестового пристрою).

## Зовнішні залежності під час роботи

Інсталятори для Windows/Linux містять ffmpeg/ffprobe та rs-ffmpeg/rs-xorriso (див. `src-tauri/src/engine/sidecar.rs` і `plugins.rs`);
якщо їх немає, використовуються інструменти з `PATH`. У macOS ffmpeg і оригінальний xorriso не входять до комплекту.

## Розробка

```bash
npm install
npm run tauri dev
cd src-tauri && cargo test --lib -- --test-threads=1
```

## Завантаження / інсталятори

Windows (.msi/.exe), macOS (.dmg, Intel/Apple Silicon), Linux (.deb/.rpm/.AppImage) і Android (універсальний APK) доступні на
[GitHub Releases](https://github.com/aon-co-jp/make-disk/releases/latest). Push тегу `v*` збирає всі платформи через
`.github/workflows/release.yml`. Сторінка проєкту: <https://easy-web.tokyo/make-disk/>
